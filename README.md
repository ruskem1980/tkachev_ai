## The method — verifiability by construction

One principle, implemented per domain. Four pillars:

- **Deterministic computation over model trust.** Numbers, dates, and aggregates are computed by code, not by the language model. The model states a value it was handed; where a figure is critical, the model does no arithmetic at all.
- **Grounding to the source.** Every claim is tied to a verbatim fragment of the source — a quote must be a substring of the original; number/date extraction is typed and robust to OCR noise. The model cannot cite what isn't there.
- **Verification and honest abstention.** An independent critic (a different model, not self-grading) and a semantic guard sit on top of the first pass. When evidence is insufficient, the system says *"not enough data"* instead of guessing. Refusal is a feature, not a failure.
- **Measurement over marketing.** Accuracy is measured against an expert-labeled set and reported as-is — including where the target isn't reached yet. In a market where almost everyone inflates, an honest number is a trust asset.

The verification loop is model-agnostic: it wraps whatever model runs underneath. The differentiator isn't a "better model" — it's the verifiability built around it, which cloud tools don't have by design.
